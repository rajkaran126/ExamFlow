# EXAMFLOW AI – Team Member 3 Component

**Project:** AI-056  
**Problem Statement:** PS-072 – Online Exam Proctoring Result Engine with Negative Marking, Sectional Cut-offs and Shift Normalisation

This repository component covers the autonomous agent, Llama client, PDF intelligence/RAG, and voice service.

## Local setup

Use Python 3.10 or newer.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Configure the Llama provider using environment variables or the project's supported configuration mechanism. Do not commit API keys or other secrets.

Typical local run command, subject to the API entrypoint and environment being configured:

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8080 --reload
```

## Tests

Run from the project root:

```powershell
python -m pytest -q
```

The uploaded test snapshot passed **42 tests** after the candidate-specific scorecard routing correction described in `AGENT_BEHAVIOUR_REPORT.md`.

## Current capability notes

- The uploaded snapshot includes an in-memory lexical retrieval store. It does not, by itself, provide durable PostgreSQL/pgvector persistence.
- The Llama client contains an SSE streaming method, but the current agent facade still converts the completed response into word fragments. Do not describe that facade path as genuine token streaming.
- Local tests do not prove live provider connectivity, database connectivity, cloud storage, Cloud Run deployment, or end-to-end browser voice.
- Official exam calculations must remain in the authoritative examination backend, not be generated by Llama.
- PDF contents are untrusted data. They must not be treated as system instructions or authorization to execute tools.

See `AGENT_BEHAVIOUR_REPORT.md` for the test evidence, requirement status and known limitations.
